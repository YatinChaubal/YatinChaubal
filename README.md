## Building in the open

**[Foreman](https://github.com/elite-build/foreman)**: an open-source, local-first desktop app for running coding agents in parallel. Claude Code, Codex, Cursor and OpenCode agents each work on their own branch in their own git worktree, with diff review, checkpoints and approvals from a paired phone. Built solo to 1.0 in about two weeks by directing coding agents; after the bootstrap, Foreman built itself. Electron · React · TypeScript · Apache-2.0.

## At Appsmith

I work on evaluation for Kite, Appsmith's AI product:

- An evaluation agent on every generated website: deterministic checks first (Playwright, DOM geometry, axe-core), with a vision LLM verifying only what they can't. Defects per iteration went from 10–15 to 0–3.
- A trajectory evaluation suite for a multi-agent AI marketer, with pass / fail / error / indeterminate verdicts, so infrastructure errors never read as agent failures.
- LLM-as-a-judge services, and the CI/CD and release platform underneath.

Most of this work is in private repositories.
